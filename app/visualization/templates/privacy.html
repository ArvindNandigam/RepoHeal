Privacy Policy

Effective date: June 15, 2026

1. Introduction

RepoHeal is a GitHub App that analyzes repositories to provide health reports, migration intelligence, and monitoring. This policy explains what data RepoHeal collects, why it is collected, where it is stored, and how it is handled.

2. Information Collected

RepoHeal collects the following information:

  • GitHub account identifiers — username, avatar URL, and GitHub user ID for authentication and repository access.
  • Repository metadata — repository name, description, visibility (public or private), default branch, file listing, and commit history relevant to analysis.
  • Dependency information — declared dependencies from requirements files and detected imports from source code.
  • Analysis results — AST scan data, dependency graphs, fingerprints, health scores, risk assessments, and migration reports derived from repository contents.
  • Health and monitoring data — health score snapshots, alert configurations, watchlists, and monitoring preferences.
  • Application logs — operational logs including request timestamps, error events, and job status transitions. No credentials or sensitive payloads are logged.

RepoHeal does not sell user data. Data is collected and processed solely to provide repository analysis and migration intelligence.

3. Repository Content

Repository contents are downloaded temporarily to perform analysis. Source code is scanned for imports, API usage patterns, and dependency declarations. The following applies:

  • Source code is processed in memory where possible. Disk extraction is used only when necessary and is cleaned up after analysis completes.
  • Analysis artifacts (dependency graphs, fingerprints, reports) may be retained. Extracted source code is not permanently stored.
  • No source code is shared with third parties beyond the analysis pipeline described in Section 4.

4. Third-Party Services

RepoHeal uses the following third-party services. Each service receives only the data necessary for its function:

  • GitHub — repository content access, OAuth authentication, webhook events, and pull request creation.
  • MongoDB Atlas — stores application state, analysis results, cache data, monitoring records, and session tokens.
  • Neo4j AuraDB — stores knowledge graph data (repository structure, symbol relationships, dependency edges).
  • Groq — LLM-based migration intelligence and patch generation. Library names and symbol names are sent; full source files are sent only during patch generation.
  • Serper — web search for deprecated API discovery. Library and symbol names are sent as search queries.
  • PyPI — version lookups for installed Python packages.
  • Render — hosting platform for both RepoHeal and the Restricted Webtool microservice.

5. Data Security

RepoHeal implements the following security measures:

  • All traffic between users, GitHub, and RepoHeal is encrypted over HTTPS.
  • API keys, credentials, and secrets are stored as environment variables, not in source code or databases.
  • Session tokens are encrypted at rest using Fernet symmetric encryption with a key stored in environment variables.
  • GitHub App permissions are scoped to the minimum required for analysis functionality. RepoHeal does not request admin or delete permissions.
  • Webhook payloads from GitHub are verified using HMAC-SHA256 signatures.

6. Data Retention

Data is retained only as long as necessary to provide analysis and monitoring functionality:

  • Analysis history is capped at 2 records per repository.
  • Cache entries expire after 7 days.
  • Session tokens expire after 24 hours and are cleaned up automatically.
  • Evidence cache entries have a 30-day time-to-live.

When you uninstall the RepoHeal GitHub App, analysis and monitoring data associated with your repositories may be retained in operational backups. Contact the address in Section 8 to request deletion of stored data.

7. User Rights

You have the following rights regarding your data:

  • Uninstall — you can remove RepoHeal from your GitHub account at any time through GitHub App settings.
  • Access — you can view all analysis reports, health data, and monitoring configurations through the RepoHeal dashboard.
  • Deletion — you can request deletion of stored data by contacting the address in Section 8.
  • Correction — analysis results are automatically regenerated on each analysis run. Triggering a new analysis replaces prior results.
